# QA Flow Intelligence

AI-powered QA intelligence platform focused on requirement analysis, risk detection, and practical test case workflow support.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui

## Local Setup

```bash
npm install
npm run dev
```

Optional checks:

```bash
npm run lint
npx tsc --noEmit
```
